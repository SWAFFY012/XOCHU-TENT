# Хочу Тент — сайт производства

Next.js 16 (App Router, Cache Components) + TypeScript + Tailwind 4 + framer-motion.

## Запуск

```bash
npm install
cp .env.example .env.local   # заполнить токен бота и chat_id
npm run dev                  # http://localhost:3000
npm run build && npm start   # продакшен
```

Без `TELEGRAM_BOT_TOKEN` в dev-режиме заявки печатаются в консоль сервера, в продакшене API отвечает 503.

## Данные

- `data/prices.xlsx` — прайс (выгрузка Ozon). После замены выполните `npm run data`.
- `data/products.json` — 12 товаров и все варианты. Читается только на сервере (`lib/catalog.ts`).
- Каталог получает сводку без вариантов, карточка — сжатые варианты одного товара.

## Фото товаров

Фото берутся из папок с карточками маркетплейса (как в архиве «Главные для сайта»):

```bash
npm run images -- "<папка товара>" <slug>
# пример: npm run images -- "D:/Главные для сайта/Сетка" setka-tenevaya --alias="84=брезентовая хаки;88=пвх коричневый;92=пвх хаки"
```

Скрипт сам сопоставляет цвета/пропитки и размеры с прайсом, отбрасывает обращения маркетплейсов
(«Дорогие покупатели», ВБ/ОЗОН) и пишет WebP в `public/products/<slug>` + манифест `data/media/<slug>.json`.

## Яндекс Метрика

Счётчик подключается переменной `NEXT_PUBLIC_YM_ID` (см. `.env.example`), без неё на сайте нет ни скрипта, ни запросов. Включены Вебвизор, карта кликов, просмотры страниц при переходах и электронная коммерция (`dataLayer`). Код: `lib/metrika.ts`, `components/analytics/`.

В кабинете Метрики создайте цели типа «JavaScript-событие» с этими идентификаторами:

| Идентификатор | Когда срабатывает |
|---|---|
| `add_to_cart` | товар добавлен в корзину |
| `order_submit` | заказ оформлен на сайте (до оплаты) |
| `lead_submit` | отправлена заявка (мягкие окна, свой размер) |
| `order_paid` | заказ оплачен (страница «Заказ оплачен») |
| `phone_click`, `email_click` | клик по телефону, почте |
| `telegram_click`, `whatsapp_click`, `ozon_click` | клик по Telegram, WhatsApp, магазину на Ozon |

Цели по секциям главной (`components/analytics/SectionTracker.tsx`): секция должна быть на экране нужное время при активной вкладке, цель уходит один раз за визит.

| Идентификатор | Секция | Время на экране |
|---|---|---|
| `hero_10s`, `hero_30s` | первый экран | 10 и 30 секунд |
| `view_season` | «Готовы к зиме» | 3 с |
| `view_calc` | калькулятор нестандартного размера | 3 с |
| `view_process` | «Как мы шьём» (этапы) | 4 с |
| `view_custom_size` | «Любой размер за 1–3 дня» | 2 с |
| `view_materials` | сравнение материалов | 4 с |
| `view_faq` | частые вопросы | 3 с |
| `view_cta` | финальный призыв | 2 с |

Активное время в разделах (`components/analytics/PageTimeTracker.tsx`): вкладка видна и за последние 60 секунд были движения мыши, прокрутка, касание или ввод. Время копится по разделу за визит, каждая цель уходит один раз. Пороги (`TIME_STEPS` в `lib/metrika.ts`): идентификатор `time_<раздел>_<секунды>s`.

| Раздел | Пороги | Примеры идентификаторов |
|---|---|---|
| «О производстве» (`/about`) | 30 с, 1, 2, 5 мин | `time_about_30s` … `time_about_300s` |
| каталог и карточки (`/catalog`, `/catalog/…`) | 30 с, 1, 2, 5, 10, 20, 30 мин | `time_catalog_30s` … `time_catalog_1800s` |
| корзина и оформление (`/cart`) | 30 с, 1, 2, 5, 10, 20, 30 мин | `time_cart_30s` … `time_cart_1800s` |

Просмотры страниц (карточки товаров, «О производстве», «Доставка и оплата», «Контакты») в коде не отслеживаются: для них в Метрике создаются цели типа «Посещение страницы» по адресу.

Основная конверсия для рекламы — `order_submit` и `lead_submit`. Цель `order_paid` заработает, когда включена онлайн-оплата (`NEXT_PUBLIC_PAYMENTS_ENABLED=true`).

## Где менять заглушки

Всё в **`lib/site.ts`**: телефон, адрес, реквизиты, домен, координаты карты, сроки, плотности материалов (`materialSpecs`). Фото товаров — через `npm run images` (см. выше).
Тексты товаров, FAQ и категории — в `lib/content.ts`. Строки с пометкой `TODO` нужно проверить перед запуском.

## Структура

| Путь | Что |
|---|---|
| `app/page.tsx` | главная: вступление, hero-видео, «Готовы к зиме», этапы и материалы (горизонтально), калькулятор, FAQ |
| `app/catalog` | каталог, фильтры в URL (`?cat=&mat=&color=&max=&sort=&q=`) |
| `app/catalog/[slug]` | страница товара (статическая) |
| `app/@modal/(.)catalog/[slug]` | та же карточка поверх каталога, выезжающей панелью |
| `app/cart` + `app/api/lead` | заявка → Telegram, цены пересчитываются на сервере |
| `components/motion` | переходы страниц («ступени»), плавный скролл (Lenis), горизонтальные главы (`PanelChapter`), вступление (`RapidLayersIntro`, Codrops), буквенные заголовки (`SplitReveal`) |
| `components/home` | секции главной: hero, «Готовы к зиме», заставка, этапы и материалы, калькулятор |

Компоненты `StairsTransition` и `CurtainCard` адаптированы из 21st.dev (Page Transition, Card Curtain Reveal).
Видео: `public/hero-720.mp4` (компьютеры и планшеты, около 480 кбит/с, 3,3 МБ) и `public/hero-mobile.mp4` (телефоны, вертикальный кадр 406×720 по центру, около 330 кбит/с, 2,3 МБ), кадрированы из 4:3 в 16:9. Хостинг Hostland отдаёт файлы со скоростью около 90 КБ/с на соединение, поэтому видео должно быть легче этой скорости; Hero подставляет `src` после заставки (`<source media>` в video браузеры не поддерживают).
